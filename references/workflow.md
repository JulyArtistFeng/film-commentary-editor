# 影视解说剪辑 · 详细工作流

开始执行影视解说任务时完整读取。

---

## 第一步：获取并分析素材

### 素材获取
- 本地视频：直接使用
- 在线链接（B站/YouTube等）：用 doubao-video-extract 下载
  ```bash
  doubao-video-extract "URL" --output ./source_video.mp4
  ```

### 内容分析
用 byted-mediakit-video 分析视频：
- 提取剧情时间轴：关键场景、转折点、高潮
- 识别人物：主要角色、关系
- 标记名场面：经典台词、震撼画面、搞笑瞬间
- 识别适合开头的劲爆片段

### 输出分析报告
```
影片：{片名}
时长：{原片时长}
核心冲突：{一句话}
关键转折点：[{时间点}, {事件}]
名场面：[{时间点}, {描述}]
适合开头：[{时间点}, {为什么抓人}]
解说视频目标时长：{5/10/15分钟}
```

---

## 第二步：生成解说文案

### 文案结构比例
| 部分 | 占比 | 内容 |
|---|---|---|
| 开头钩子 | 5% | 劲爆观点/问题，3-5秒抓人 |
| 背景铺垫 | 10-15% | 快速交代故事背景 |
| 剧情推进 | 55-65% | 边讲边吐槽，穿插解读 |
| 高潮解读 | 10-15% | 核心冲突/反转深度分析 |
| 结尾 | 5-10% | 总结评价+金句+引导关注 |

### 字数控制
- 5分钟视频：1000-1200字
- 10分钟视频：2000-2400字
- 15分钟视频：3000-3600字
- 语速：每分钟 220-250 字

### 文案写作要点
- 每 30 秒至少一个记忆点（金句/吐槽/反转）
- 不单纯复述剧情，必须有观点和态度
- 关键情节配犀利点评
- 烂片：重点吐槽逻辑漏洞、演技、特效
- 好片：重点解读隐喻、细节、表演
- 中庸片：找独特角度（导演风格、演员表现、社会意义）

---

## 第三步：生成旁白音频

### text_to_audio_plus 参数
```
prompt: "35岁沉稳磁性男声，毒舌电影解说风格，语速偏快，吐槽时带笑意，煽情时放低沉，说：{文案}"
```

### 声音特征
- 音色：低沉、有磁性、略带沙哑
- 语速：220-250 字/分钟，比正常快
- 情绪：随文案变化，不是平铺直叙
- 标志性：句尾略带调侃语气

### 分段生成
- 文案较长时按段落分段生成，每段 300-500 字
- 分段后用 byted-mediakit-editing 拼接
- 拼接处注意语气连贯，可加 0.3 秒静音过渡

---

## 第四步：镜头设计与素材剪辑

### 镜头语言对照表

| 文案情绪 | 镜头处理 | 时长 |
|---|---|---|
| 劲爆/吐槽 | 快切，1-2秒一切 | 短 |
| 煽情/震撼 | 慢放+特写 | 长 |
| 关键金句 | 定格+放大+字幕 | 2-3秒 |
| 剧情推进 | 正常速度，按情节切 | 中 |
| 对比/反差 | 前后画面对比剪辑 | 中 |
| 悬念 | 黑屏+音效 | 1-2秒 |

### 剪辑操作（byted-mediakit-editing）
1. 按文案逐句匹配影片片段
2. 裁剪高光片段，剔除冗余
3. 快切：片段之间硬切，无转场
4. 慢放：0.5倍速，用于煽情/震撼
5. 定格：最后一帧静止 1-2 秒，配金句
6. 缩放：放大关键细节（表情、道具）
7. 转场：情绪转折处用淡入淡出

### 素材不足时
- 用空镜（环境、道具、城市）过渡
- 用海报/剧照+缓慢推拉
- 用字幕+纯色背景承接

---

## 第五步：字幕与特效

### 字幕
- 旁白逐句显示，底部居中
- 关键词加粗/变色（红色=吐槽，黄色=重点）
- 金句：放大、居中、配打字机动画
- 吐槽标签："离大谱""绝了""导演你出来"花字

### 特效
- 转场：快切为主，情绪转折淡入淡出
- 画面：关键处缩放、旋转（吐槽时可加轻微抖动）
- 音效：笑声、惊叹、"叮"、唱片刮擦声

---

## 第六步：配乐与合成

### BGM 选择
| 影片类型 | BGM 风格 |
|---|---|
| 悬疑/惊悚 | 低沉弦乐、心跳节奏、环境音 |
| 喜剧 | 轻快俏皮、滑稽音效 |
| 动作 | 电子乐、摇滚、鼓点密集 |
| 爱情/煽情 | 钢琴、弦乐、渐强 |
| 烂片吐槽 | 滑稽音乐、反转音效 |

### 配乐原则
- BGM 随文案情绪切换，不一首铺到底
- 旁白为主音轨，BGM -15 到 -20dB
- 高潮处 BGM 渐强，吐槽处 BGM 减弱或静音
- 关键金句处 BGM 停顿，突出人声

### 片头片尾
- 片头（3-5秒）：影片名+解说标题，配快闪画面+劲爆BGM
- 片尾（5-8秒）："关注我，下期更精彩"+下期预告+关注动画

### 输出
- MP4，1080p，16:9
- 码率：8-12 Mbps
- 音频：320kbps AAC
